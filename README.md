# 감사파일 개인정보 마스킹 자동화

감사실 감사파일(hwp/hwpx/pdf)에 포함된 개인정보를 수기로 하나씩 마스킹하는 작업을 줄이기 위한 도구입니다.
완전 자동화가 아니라 **"자동 탐지 + 사람의 최종 검토/승인"** 구조로 설계되어 있습니다 — 이름/주소 같은 항목은 자동 탐지가 100% 정확할 수 없다는 전제하에, 사람이 검토 단계에서 최종 확인합니다.

개인 프로젝트로 진행 중이며, 실제 감사파일은 아직 사용하지 않습니다 (자세한 내용은 설계서 2.1 참고).

## 현재 상태

**PDF 입력 기준 MVP 구현 및 end-to-end 검증 완료.**

- 아키텍처 설계는 v14까지 정리됨 (타당성 평가 포함)
- PDF 파일을 넣으면 탐지 → 검토(문서유형 선택, 텍스트 기반 수동 추가 포함) → 마스킹 → 자체검증(실패 시 검토 화면 복귀) → 파일명 규칙에 맞춰 저장 → 원본 보관 이동 → 로그/요약리포트 기록(자동/수동 탐지출처 구분 포함)까지 전체 파이프라인이 실제로 동작함 (더미 데이터로 검증)
- 개발 중 발견한 버그 다수를 실제 재현 테스트로 확인 후 수정함 (예: 마스킹 텍스트 폰트 크기 축소, 전화번호/계좌번호 이중탐지, 이메일 1글자 로컬파트 미마스킹, 파일명이 겹치는 원본이 보관 폴더에서 서로 덮어쓰던 문제, 자체검증 실패 시 실제 개인정보 값이 콘솔에 그대로 노출되던 문제, 주석/폼필드/첨부파일을 존재만 감지하고 실제로는 제거하지 않던 문제 등)
- 카드번호 탐지 추가 (계좌번호만 있고 빠져있던 범위 항목)
- 여러 파일 순차 처리(배치) 지원 — 파일마다 검토 화면을 거치는 방식(자동 일괄처리 아님), 한 파일이 실패해도 나머지는 계속 진행
- 재실행(중복 마스킹) 방지 — 마스킹완료/ 폴더 경로 또는 문서 속성 마커로 이미 처리된 파일을 감지해 재처리 여부를 확인(완전 차단은 아님)
- 사전 자동 학습 — 검토자가 이름을 체크 해제하거나 수동으로 이름을 추가하는 행동을 조용히 누적해, 같은 단어가 3회 반복되면 성씨/제외어 사전에 자동 반영(질문 없이 통보만). 검토 화면에서 최근 반영 내역을 되돌리기 버튼으로 취소 가능
- hwp/hwpx → PDF 변환은 골격만 작성됨 (`mvp/hwp_converter.py`) — Windows + 한컴오피스 환경이 없어 실동작 검증·파이프라인 연결은 아직 못함
- **아직 없는 것**: hwp/hwpx → PDF 변환 실동작 검증 및 연결, .exe 패키징, Undo/Redo, 파일선택 다이얼로그, 실제 화면으로 클릭해보는 인터랙티브 테스트(이 개발 환경엔 디스플레이가 없어 헤드리스로만 검증함)

## MVP

PDF 입력만 지원하는 최소 동작 버전입니다 (hwp/hwpx 변환 어댑터는 범위 밖).

- [`mvp/detector.py`](mvp/detector.py) — 개인정보 탐지 엔진. 전화번호/이메일/계좌번호/카드번호/주민등록번호(체크섬 검증)/여권번호는 정규식, 이름/주소는 사전+문맥규칙 기반. `reload_dictionaries()`로 학습된 사전을 즉시 재적용
- [`mvp/masker.py`](mvp/masker.py) — 실제 리댁션(오버레이 아님) + 항목별 부분/완전마스킹(계좌·카드는 완전/부분 전환 가능한 설정값) + 저장 전 자체 재검증 + 메타데이터 제거(재실행 방지용 마커는 남김) + 주석/폼필드/첨부파일 실제 스캔·제거(OCG는 구조적 한계로 존재 감지만)
- [`mvp/review_ui.py`](mvp/review_ui.py) — 최소 검토 화면 (PySide6). 기본 전체 승인 상태에서 예외만 체크 해제, 문서유형 선택(결과 파일명에 사용), 텍스트 검색 기반 수동 추가(드래그/클릭 방식은 실제 화면 테스트 가능해지면 추가 예정), 자체검증 실패 시 재시도 안내·항목 하이라이트(실제 값은 표시하지 않음), 재실행 감지 시 확인 다이얼로그, 사전 자동학습 반영 내역 + 되돌리기
- [`mvp/dictionary_learning.py`](mvp/dictionary_learning.py) — 사전 자동 학습(6.2.1). 체크 해제/수동 이름 추가를 후보로 누적, 3회 반복 시 조용히 사전에 반영·이력 기록, 최근 반영분 되돌리기 지원
- [`mvp/logger.py`](mvp/logger.py) — 감사 로그(CSV, 원본 SHA-256 해시 포함) + 처리 결과 요약 리포트(1장) 기록
- [`mvp/archive.py`](mvp/archive.py) — 결과물 파일명 규칙(`[문서유형]_[처리일자]_[일련번호].pdf`) + 원본 자동 보관 이동 + 마스킹완료/ 폴더 경로 판별(재실행 방지용)
- [`mvp/hwp_converter.py`](mvp/hwp_converter.py) — hwp/hwpx → PDF 변환 어댑터 골격 (Windows + 한컴오피스 환경에서만 동작, 실측 전)
- [`mvp/main.py`](mvp/main.py) — 위 모듈들을 잇는 진입점
- [`mvp/data/`](mvp/data/) — 성씨/제외어/행정구역 사전 (사용하면서 자동 학습으로 갱신됨)

**실행 방법** (디스플레이가 있는 PC에서):
```
pip install pymupdf pyside6
python3 mvp/main.py 파일1.pdf [파일2.pdf ...]
```
파일마다 탐지된 항목과 문서유형 선택을 보여주는 검토 창이 순서대로 뜨고(대기열), 승인하면 `마스킹완료/[문서유형]_[처리일자]_[일련번호].pdf`가 생성되고 원본은 `원본_보관/`으로 이동합니다. 여러 파일을 한 번에 넘겨도 자동으로 일괄 처리되지 않고 파일마다 사람이 검토합니다.

## PoC (Proof of Concept)

MVP 이전에, 더미 데이터로 핵심 기술 전제("마스킹이 오버레이가 아니라 진짜로 지워지는가")만 좁게 검증했던 초기 스크립트입니다. 실제 감사파일은 사용하지 않습니다.

- [`poc/masking_poc_test.py`](poc/masking_poc_test.py) — 정규식 탐지, 실제 리댁션(오버레이 아님), 자체 재검증, 메타데이터 제거, 회전된 텍스트 실패 케이스 검증
- [`poc/masking_poc_partial.py`](poc/masking_poc_partial.py) — 부분마스킹(`홍길동` → `홍*동`)이 리댁션 + 텍스트 재삽입으로 정상 렌더링되는지 검증
